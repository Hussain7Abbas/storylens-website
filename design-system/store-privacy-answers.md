# Store disclosure draft

Owner must review and submit through store dashboards; no store submission is part of the automated deployment.

Single purpose: improve web-novel reading through character reference highlighting, replacement rules, chapter recognition, and user-requested summaries.

Permissions: tabs for active-page actions; storage for preferences and pairing; alarms for sync; unlimitedStorage for offline reference data; HTTP(S) content scripts for reading tools; API host access for catalogue/accounts/sync; loopback host access for the paired companion.

Data categories to disclose: account identifiers and credentials; contributed/reference catalogue content; website/page information for requested selector detection and summaries; necessary security/network diagnostics. Summaries reach the user-selected provider; detection reaches OpenRouter/upstream provider; uploads reach ImgBB. State that reference content is shared, not private.

Data is not sold, used for ads, or used for credit/lending. Do not claim Google API Limited Use certification because those APIs are not integrated. Chrome privacy URL: https://storylens.iscoded.com/en/privacy/ . Firefox source build exists but no live AMO listing is verified. Use the same data handling disclosure when listing Firefox.
